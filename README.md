## If you installed a skill from here

The copies that used to live in this repo are an earlier version. They used rules that are no longer part of the method, including 1-10 scores that triggered exclusions and an estimated CPA drop. Replace them with the current versions from the repos above.

If you added this repo as a Claude Code plugin marketplace, remove it:

```
/plugin marketplace remove tnt-skills
```

The full library is at [tntgrowth.com/skills](https://tntgrowth.com/skills?utm_source=github&utm_campaign=treboutat).
